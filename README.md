TechTatva 2025 Gallery
A responsive photo gallery website created to showcase event photographs from TechTatva 2025. The gallery organizes images by event day and provides a smooth browsing experience with a clean interface.

Live Demo
https://staticfile-shettysanmitha116.wasmer.app/

Features
Day-wise image gallery
Responsive masonry layout
Full-screen image preview
Previous and next image navigation
Mobile swipe support
Lazy loading for improved performance
Background video for an immersive experience
Dynamic photo counter
